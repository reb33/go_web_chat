очередной web чат

## Требования:
1. back на go
2. использование echo для общение с мордой
3. морда на htmx
4. web-socket для общения в чате
5. база на pstgres
6. миграции на liquebase
7. использование taywing
8. добавление метрик

## Структура проекта

```
.
├── cmd/
│   └── app/
│       ├── main.go              # Точка входа: конфиг, логгер, Sentry, пул БД и старт App
│       ├── app.go               # Composition Root: сборка всех слоев и запуск сервера
│       └── debug_server.go      # Internal-only pprof-сервер на 127.0.0.1 (см. "Профилирование")
├── config/
│   ├── config.go                # Структура конфигурации приложения
├── docs/
│   ├── docs.go                  # Конфиг для генератора документации
│   ├── swagger.json             # Swagger JSON
│   └── swagger.yaml             # Swagger YAML
├── internal/
│   ├── domain/                  # Слой бизнес-логики (не зависит ни от чего)
│   │   ├── entities/            # Доменные модели (структуры без тегов)
│   │   └── services/            # Доменные сервисы (чистая логика расчетов/валидации)
│   ├── usecase/                 # Сценарии использования (оркестрация)
│   │   └── health/              # Health-check юзкейс
│   ├── infrastructure/          # Реализация внешних зависимостей
│   │   └── postgres/            # Пул соединений pgx и репозитории
│   └── transport/               # Слой доставки (API)
│       └── httpserver/
│           ├── router.go        # Инициализация Echo и middleware
│           ├── ports/           # Интерфейсы, требуемые транспортом
│           ├── responses/       # Общие структуры ответов API
│           └── v1/              # Версионирование API
│               ├── v1.go        # Группировка роутов и Deps
│               └── handlers/    # Функциональные хендлеры
├── migrations/
│   └── changelog.xml            # миграции
├── pkg/                         # Вспомогательные библиотеки
│   └── sentryslog/              # slog-хендлер с отправкой ошибок в Sentry
├── go.mod
├── go.sum
└── README.md
```
